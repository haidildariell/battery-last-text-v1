## Entry

> You plugged me in for 40 seconds, called it charging, and walked away. I hope your alarm clock dies the same way.

## How it works

`main.py` is a small deterministic Python 3 program with no network access and no dependencies. Run it and it writes the entry text above, plus a single trailing newline, to `/output/entry.txt`.
